# 摩擦报告 · 操作系统（第三批）

## os-clock　简单 CLOCK 的过程表

### 理想的教法
1. 先用一个「访问位全是 1」的小场面让学生**自己转指针**：学生在环形的三块上一下一下点「指针走一格」，每走一格页面把访问位清 0；学生自己决定在哪一块停下换出。这样「为什么转一圈」是学生亲手转出来的，而不是看出来的。
2. 然后学生自己填考卷上那张过程表（每块的页、访问位、指针、缺页、换出），页面逐格批。
3. 最后一句话说清「转一圈」的原因，再换串练。

### 现有组件做到了
- `paging algo: clock` 配 `init: 1 1, 2 1, 3 1`、`ptr: 1`、`refs: 4 2 1`、`ask: hit, victim`：从「全是 1」开始，学生先判命中、再点换出，页面画出指针一路清 0（第 1 板）。访问 2 命中、访问 1 时第 2 块被「第二次机会」放过，也能在同一个小例子里看到。
- `paging mode: fill`：说明写明 clock 的 fill 就是「考卷上那张过程表」（每块的页、访问位、指针、缺页、换出），页面逐格批、标第一处错（第 2 板）。
- `paging mode: quiz` 数缺页（9 由页面算，我不用写）；`practice use: paging algo: clock quiz: victims` 换串练。

### 想做但做不到的
- **学生自己转指针**：`ask: victim` 只问最后换谁，指针中间扫过、清 0 的过程都是页面自己画的。想要 `mode: do`：学生每点一次，指针走一格（访问位 1 → 清 0），学生觉得该换了就点「换出」，页面判每一下。CLOCK 最容易错的就是「扫的时候清 0」和「命中时指针动不动」，现在这两点只有到 fill 的表里才暴露。
- **缺页总数**：fill 的表里有缺页打勾，但说明没写表下面有没有「缺页次数」那一格，我只好在第 3 板放一个同样输入的 `mode: quiz` 再数一次，有点重复。
- **一句话的理由**：实时黑板里 `conjecture` 不批改，我得自己读。
- 想在过程表上指着「第 4 次访问那一列」讲：实时黑板的 `mark … item=` 是按「第几个格子」数，表格里第几个格子是哪一个我数不出来（看不到页面）。

### 写法上拿不准、只能猜的地方
- **冷启动时指针动不动**：前 3 次调入空闲块时，指针是跟着往后走，还是一直停在第 1 块？说明没写。我在常驻栏里没敢写这一点，用 `given: 3` 把前 3 列直接给出，让学生照页面的口径往下填。如果页面口径和学生做的王道题不一样，学生会被这三列带偏，我也没法提前知道。
- `given: 3`：说明写「前 2 行 / 列直接给出」，对 `paging` 来说是前 3 **列**（前 3 次访问）还是前 3 **行**（前 3 个物理块）？我按「一列一次访问」理解成前 3 次访问，但没有把握。
- `init:` + `ptr:` + `refs:` 一起写、不写 `frames:`：按说明「这时 frames: 可以不写」写的。`init:` 里三块用逗号隔开、每块「页 访问位」，我写成 `1 1, 2 1, 3 1`。
- `ask: hit, victim` 在 `init:` 那种已经满了的开局里，`hit` 是每次都问吗（第 1 板只有 3 次访问，问题不多，问题不大）。
- `practice use: paging` 只写 `algo: clock`：内置出题的引用串有多长、几个物理块、会不会正好出现「全是 1」的情况？说明没写，没法保证练到关键情况。

## os-lru-drill　LRU 练到熟

### 理想的教法
1. 先用一个小题探「命中算不算新」（LRU 和 FIFO 最常混的地方），能把两种想法分开。
2. 例题推一遍：每次访问学生先判命中 / 缺页、点换出谁，看「最近使用的先后」怎么变。
3. 页面换串出题，练够 3 道，判每一个换出的页；最后 FIFO / LRU 混着练，逼学生先看算法再动手。

### 现有组件做到了
- `quiz` 单独探误解（第 1 板），选 4 的就是按 FIFO 想。
- `paging algo: lru` + `ask: hit, victim, faults`（第 2 板）。说明写了 LRU 下面有「最近使用的先后」，正好对照。
- `practice use: paging algo: lru quiz: victims count: 3`（第 3 板）：页面换串、判每一个换出的页，错法诊断能看出「按 FIFO 换的」。
- 第 4 板用 `pick a = word(fifo, lru)` 让页面挑算法、`pick r = seq(12, 0, 5)` 出引用串。

### 想做但做不到的
- **LRU 的「栈」**：想让学生在每次访问后自己把「最近使用的先后」拖成新的顺序（被命中的拖到最上面），页面判。现在这一行只能看，`mode: fill` 也只填各物理块和换出谁，不填这一行。学生到底是在维护先后、还是在往回数，看不出来。
- 想按难度递进出题（第 1 道 8 个引用、第 3 道 12 个、4 个物理块），`practice` 的 `count` 只有一个总数，不能「前一道这样、后一道那样」；只能放两个 practice。

### 写法上拿不准、只能猜的地方
- `ask: faults`：说明只写「一共缺页几次」，是**开头先猜**还是**走完以后问**？如果是开头先猜，13 次访问之前就猜总数没什么意义；我还是写上了。
- `practice use: paging` 配 `quiz: victims`：说明说「同名字段照你写的」，`quiz:` 算不算同名字段？我猜算。
- 第 4 板：`algo: \calc{a}`——`word()` 取到的是一个词，写进 `algo:` 是不是 `\calc{a}`？说明只写了 word 是「挑一个词：算法名、方向」，没写怎么写进字段。我还担心学生在题面上看不出这题是哪种算法：页面会不会把 `algo` 写在题面上？我只能在说明文字里写「看题目里写的算法」。
- 第 4 板写了 `pick` 以后，是不是所有字段都要自己给（所以我又 pick 了引用串）？只写 `algo` 的时候内置出题还管不管 `refs`？说明的「只写 `use:` 用内置的出题」和「别的出法照自定义题型写 pick」之间没说清能不能混着用。
- `seq(12, 0, 5)` 会不会取出一串几乎没有缺页 / 没有换出的引用串（比如全是 0 1 2）？`where` 能不能配 `use:` 用（比如 `where` 换出次数 ≥ 3）？说明没写，表达式里也没有算缺页次数的函数。

## 说明里第一次见到、拿不准的新写法
- `paging` 的 `init:` / `ptr:`（简单 CLOCK 的开局状态）：只在完整写法里一句话，格式是我照「页 访问位」推的。
- `mode: fill` 配 `given: 3` 用在 `paging` 上：行还是列不清楚。
- `practice use: paging` + `quiz: victims`：没有现成例子。
- `pick a = word(fifo, lru)` + `algo: \calc{a}`：word 怎么写进字段没写；practice 里内置出题和自己 pick 能不能混用没写。
- `ask: faults` 的时机。

## 如果组件库只能再加三样
1. **`paging` 的 `mode: do`**：学生自己拨指针（CLOCK）、自己挪「最近使用的先后」（LRU）、自己点换出，页面每一下判。过程类的置换题，最难的是那一下下的操作，不是最后的结果。
2. **表达式里的模拟函数**：`faults(refs, 3, lru)`、`victims(...)`，能用在 `where` 和 `\calc` 里：出题时保证「至少换出 3 次」「LRU 和 FIFO 的结果不一样」，题面和讲解里的数也是页面算的。
3. **按「第几次访问」标注、跳转**：`mark target=pg-fill col=4`、`figure set step=` 按访问序号而不是内部步号。老师看不到页面，数不出第几个格子、第几步。
