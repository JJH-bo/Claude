# 摩擦报告 · 数据结构（第三批）

## ds-nextval　next 和 nextval，练到熟

### 理想的教法
1. 学生自己一格一格求 next：每一格在模式串上**自己拖出**前缀和后缀（两条可以拖长短的括号），页面判「相等吗、是不是最长」，再写 next[j]。
2. 用一次真实的匹配让学生看到「退回去还是同一个字母」的浪费：在匹配过程里**点出那几次白比的比较**，页面判对错。
3. nextval：学生每一格先判断 $P_j$ 和 $P_{\text{next}[j]}$ 是否相同，相同时沿着「j → next[j] → …」的链往前点，页面画出这条链。
4. 学生一句话说出规则，然后页面换串出题练到熟，逐格判。

### 现有组件做到了
- `kmp show: next` + `ask: next`：学生每格先填，页面画前后缀对照（第 1 板）。
- `kmp text: … ask: slide`：真实匹配里每次失配让学生猜 j 退到几，能看到 aaaab 那种一退再退（第 2 板）。
- `quiz`：把「同一个字母再比一定失配」的道理单独问出来，能分开「懂了」和「没懂」两种想法。
- `kmp show: nextval` + `ask: nextval`（第 3 板）、`mode: fill` 整张表自己填（第 4 板）。
- `practice use: kmp` + `pick s = str(8, ab)` + `mode: fill`：页面换串、逐格判（第 5 板）。
- 错法诊断能认出「nextval 照抄 next」「按 next[0] = −1 算」「写成 PM」，读记录时可以追问。

### 想做但做不到的
- **学生自己拖出前后缀**：`ask: next` 只能填一个数，页面画的前后缀是揭晓以后才看到的。填对了也看不出是数对了还是背了公式。想要「在模式串上拖两段，页面判是不是相等、是不是最长」。
- **在匹配里点出白比的那几次比较**：第 2 板只能猜「j 退到几」，没法让学生指着说「这一次比较是多余的」。我只好另放一个 `quiz`，而且 quiz 里 `next[3]` 指向 $P_1$ 这件事是我在题面里**手写**的——表达式里没有求 next / nextval 的函数，不能 `\calc{next("abaabcac")}`，换串时也没法让题面跟着变。
- **nextval 的「链」**：想让学生在 nextval 那一步点出 j → next[j] → next[next[j]] 这条链，页面判点得对不对。现在只能填最后的数。
- **一句话的规则只能自己看**：实时黑板里 `conjecture` 是 `grade: off`，学生交完没有任何反馈，要等我读。

### 写法上拿不准的地方
- `ask: next` 是每一格都问，还是只问 j ≥ 3 的（next[1]、next[2] 是固定的）？说明只写了「这一格是多少」。
- `show: nextval` + `ask: nextval`：画面是先把 next 一步步求一遍再求 nextval，还是 next 直接给出？如果 next 也一步步走，学生要连点 8 次「下一步」才到 nextval，第 3 板会很拖。
- `practice use: kmp` 里把随机串写进 `pattern:`：说明只写了「向量用 `\calc{list(v)}`」「`bits` 写出来就是 1011」，**`str()` 取到的串怎么写进字段没写**，我猜的是 `pattern: \calc{s}`。
- 只写 `use: kmp`（内置出题）时问的是 next、nextval 还是匹配位置？说明没写，所以我没敢用内置的，自己写了 `pick`。
- `practice` + `mode: fill`：说明说 `use:` 能配 `mode: fill`，但一题 16 格，练 3 题会不会太重——不是写法问题，是我不确定页面在 practice 里是不是一题一张完整的表。

## ds-avl　自己建平衡二叉树

### 理想的教法
每插一个数：学生**把新结点拖到**它该挂的位置；页面标出每个结点的 BF 后，学生点出最小不平衡子树的根；然后学生**自己动手转**——拖结点、换孩子，转成调平以后的样子，页面判这棵子树对不对（而不是只选 LL / RR / LR / RL 四个字母）。最后写层序序列。再换几组数练。

### 现有组件做到了
- `avl ask: insert, root, rotate`：点双亲、点失衡的根、选旋转类型，九个数一个个插，每一步页面判（第 2 板），已经很接近「自己建」。
- 热身用 `avl: 50 30 70 20 10` 让两个结点同时失衡，`ask: root` 专门探「找了离根最近的失衡结点」这个误解（错法诊断认得出）。
- `avl mode: quiz` 写最后的层序，答案页面算，不用我手写 `11 7 18 …`。
- `practice use: avl` + `pick v = seq(8, 1, 40) distinct` 换数再建；碰到不失衡的组页面自己换。

### 想做但做不到的
- **学生自己转**：`rotate` 只是四选一，选对了不代表会转。LR / RL 双旋转完谁当根、谁的子树挂到哪，这才是考卷上最容易错的地方；现在学生只能看页面画，自己画在纸上，页面看不到纸。想要一个「在图上拖结点重排这棵子树」的作答方式，或者至少 `ask: after`：转完以后这棵子树的先序 / 层序，学生写，页面判。
- `mode: fill` 也只填「最小不平衡子树的根、调整类型、整棵树的根」，不填转完以后的样子。
- 第 2 板问题太多：九个数 × (insert + 可能的 root + rotate)，大约 13 次作答挤在一个组件里，中间没法插一句「看这一步：LR 为什么要转两次」。想按插入的序号只问其中几次（比如只问第 3 个和第 9 个的 rotate）：`ask: 3, 7` 是步号，但我不知道每次插入对应第几步，说明里建议的办法是 `start: end` 先数——我看不到页面，数不了。

### 写法上拿不准的地方
- `ask: insert` 只出现在完整写法和「让我自己一步步建」那一条里，简写版的 `ask:` 列表里没有它，我按完整写法写了。
- `ask: bf` 问的是**哪个**结点的平衡因子？是每次插入都问一次，还是只在失衡时问失衡的那个？热身里我写了 `bf, root, rotate`，不确定 bf 会问几次。
- `avl mode: quiz` 写了 `q:`：页面会用我的 `q:` 当题面，还是自己出题面？两个都显示会重复。
- `mode: quiz` 是「只给输入」：学生还能翻回第 2 板看到最后那棵树，这道题就成了抄。这不是写法问题，但实时黑板没有办法把旧板上的结果先收起来。

## 说明里第一次见到、拿不准的新写法
- `str(8, ab)`：第一次用，说明只写了「用 a、b 拼 7 个字母」；写进 `pattern:` 用 `\calc{s}` 是我猜的（向量要 `list()`，串要不要什么函数？）。字母表能不能写三个字母 `str(8, abc)` 也没写。
- `practice use: kmp` + `show:` + `mode: fill`：「同名字段照你写的」「`mode: fill` 照组件的写法」两句拼起来推出来的，没有现成例子。
- `kmp` 的 `ask: slide`（配 `text:`）：说明只有一句「失配后 j 变成多少」，不知道是每次失配都问，还是只问第一次。
- `avl` 的 `ask: insert`：在简写列表里没有、完整写法里有。
- `practice use: avl` 时一组数「正好问不到」就自己换：我写了 `ask: insert, root, rotate`，不确定「问不到」是指三个都问不到才换，还是任何一个问不到就换（insert 每组都问得到）。

## 如果组件库只能再加三样
1. **树的「自己动手」作答**（拖结点挂上去、拖着转一棵子树），页面判结构对不对。AVL、二叉排序树删除、堆调整、红黑树都用得上；现在这些组件的 `ask` 都是「点一个 / 选一个」，最难的那一下（结构怎么变）只能看。
2. **表达式里的串函数**：`next(s)`、`nextval(s)`、`pm(s)`（返回数组），配合 `\calc`、`answer type: seq`、`practice type: custom`。这样题面里「next[3] 指向哪」可以页面算，换串出新题时说明文字也跟着变。
3. **演示组件的「按事件问」**：`ask: rotate@3, rotate@9` 这种按第几次插入 / 第几个关键字来指定问哪一次，不用知道步号。老师看不到页面，步号永远数不出来。
