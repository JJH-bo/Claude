# 摩擦报告 · 组成原理（第三批）

## co-booth　Booth 补码一位乘，练到熟

### 理想的教法
1. 学生自己写 $[x]_补$、$[-x]_补$（双符号位），页面判，错了指出是符号位还是第几位。
2. 走 Booth 的表：每一步学生**先看乘数最低两位、说加什么**，然后**自己写出加完的部分积、右移后的部分积和乘数**，页面一行一行判（不是整张表最后才批）。
3. 单独问「最后一次为什么不移位」。
4. 换数练：先整张表自己填一次，再直接写结果练 3 道。

### 现有组件做到了
- `answer type: fixed` 判双符号位的定点数，能指出是符号位还是第几位错（第 1 板）。
- `mul algo: booth` + `ask: op, result`：每一步先问加什么，最后写结果（第 2 板）。错法诊断认得出「最低两位读反」「最后一次也移位」「只加了 n 次」。
- `practice use: mul algo: booth`：`mode: fill` 自己填一整张表（1 题）、默认 quiz 写结果（3 题），数都是页面出、页面算。

### 想做但做不到的
- **`[x]_补` 的答案只能我手算**：`type: fixed` 的例子是 `answer: 11.0101`，是写死的串。表达式里有 `unsigned(-13, 6)`、`bin()`，但没有「把 −0.1101 写成双符号位定点补码」的函数，所以第 1 板的 `11.0011`、`00.1101` 是我自己算好填的——违背「数让页面算」。换数出题时也没法用 `practice type: custom` 出「写 $[x]_补$」这类题（`check: bin` 不认小数点）。
- **`mul` 的 `ask: code` 只问 $[-x]_补$**，不问 $[x]_补$，所以我把两个编码拆到 `answer` 里自己写。
- **逐行自己写部分积**：`ask: op` 只是选「加什么」，加出来的部分积、右移以后的样子都是页面画的。`mode: fill` 是「每次右移后的部分积和乘数」，不含「加完、还没移」的那一行，也不含每一步的「加什么」；而且是整张表填完一起批。最容易错的「加 $[-x]_补$ 时双符号位的进位丢掉」「算术右移补的是符号位」，学生在 fill 里错了也只看到「第一处错在这一格」。想要 `mode: do`：一行一行写，写一行判一行。
- `practice use: mul` 的内置出题：`level: 2` 难在哪（位数更多？x、y 都是负数？）说明没写，我没法挑「x 负、y 正」「x、y 都负」各练一道。

### 写法上拿不准、只能猜的地方
- `type: fixed` 的 `answer:` 能不能写表达式？说明的例子是字面量 `11.0101`，我就照写字面量。
- `[x]_{\text{补}}`：KaTeX 里下标写中文要不要包 `\text{}`？说明里的公式没有出现过「补」字的下标，我都包了 `\text{}`。
- `practice use: mul` + `mode: fill` + `count: 1`：说明说 `use:` 能配 `mode: fill`，没有例子；`count: 1` 是不是允许（会不会被当成「至少 1 题」然后一直出）？
- `mul` 的 `ask: result` 是在最后一步问，还是开头先猜？我按「最后写出乘积」理解。

## co-hamming　海明码纠错

### 理想的教法
1. 学生自己把 7 个位置分到 3 个校验组里（一张 3×7 的格子，点格子打勾），页面判。
2. 收到 1010110：学生自己算 $S_3S_2S_1$，指出错位。
3. 学生说清「为什么拼起来就是位置」，再用一个反向的小题（第 6 位错了 S 是多少）检验是不是真懂了。
4. 编码：自己算校验位、写出海明码；再换数练编码，**也练纠错**（页面随机编一个码、随机翻一位）。

### 现有组件做到了
- 分组：只能用 `quiz` 多选问 $S_2$ 一组（第 1 板），位置的二进制写成 Markdown 表格。
- `hamming recv: 1010110` + `ask: s, pos`（第 2 板），错位由页面算。
- `answer type: bin` + `answer: 6` + `width: 3`：反向小题，页面判、能指出第几位不对（第 3 板）。
- `hamming data: 1010` + `ask: k, p, code`（第 4 板），和纠正后的码对得上。
- `practice use: hamming` + `pick d = bits(4) nonzero` + `ask: p, code` 换数编码（第 5 板）。

### 想做但做不到的
- **分组的格子表**：想要一张「校验组 × 位置」的格子，学生点格子打勾，页面逐格判。`quiz` 多选只能问一组；三组都问就是三道几乎一样的选择题，板也放不下。`frames` 的 `{{…}}` 挖空能做成表，但要我手写答案、且只能文字填。
- **随机的纠错练习**：想要「页面随机取 4 位信息、编好码、随机翻一位，学生纠错」。表达式里没有海明编码的函数，`recv:` 没法用 `\calc` 写出一个「只错一位」的码；`use: hamming` 的内置出题是编码还是纠错，说明没写。所以练习只做了编码。
- **位置表也是我手写的**：二进制 111…001 是平凡的，但严格说也是我写上黑板的数。
- **「为什么」只能自己看**：`conjecture` 在实时黑板里不批改。

### 写法上拿不准、只能猜的地方
- `hamming` 没有写 `mode: quiz` 写什么（crc 写了「写余数」，hamming 没写）。所以 `practice use: hamming` 不写 `ask:` 时（默认 quiz）问什么我不知道，就显式写了 `ask: p, code`。
- `pick d = bits(4) nonzero` 写进 `data:`：说明写「`bits(4)` … 写出来就是 `1011`」，我理解成 `data: \calc{d}`；但另一句又说「`bin(g)` 是不带符号的」，不确定 bits 取出来是串还是数（是数的话 `0011` 会不会写成 `11`、丢了前导 0）。
- `ask: s`：是三个 S 分别问，还是一次写 $S_3S_2S_1$？写的时候是从 $S_3$ 写起还是 $S_1$？说明没写。
- `type: bin` 的 `answer: 6` 配 `width: 3`：按说明写出来应该要求写 `110`；不确定学生写成 `S3=1 S2=1 S1=0` 这种会不会被认。
- 多选 `quiz` 加了 `id:`：说明里 quiz 的例子没有 `id:`，但实时黑板要求会作答的组件写 `id:`，我加了。

## 说明里第一次见到、拿不准的新写法
- `answer type: fixed`：答案能否写表达式；`[x]_{\text{补}}` 中文下标的写法。
- `practice use: mul` + `mode: fill` + `count: 1`。
- `practice use: hamming` 不写 `ask:` 时默认问什么（hamming 的 `mode: quiz` 没定义）。
- `bits(4) nonzero` 写进 `data:`：前导 0 会不会保留。
- `hamming ask: s` 的作答格式。

## 如果组件库只能再加三样
1. **定点数编码的表达式**：`fixed(-0.1101, 2)`（双符号位补码）、`orig()`、`neg()` 这类，能用在 `answer`、`\calc`、`practice type: custom` 里。组成原理大半的小题是「写一个编码」，现在只能手算后写死，换数出题完全做不了。
2. **过程表的 `mode: do`（写一行判一行）**：Booth、原码一位乘、加减交替除法、CRC 的竖式，学生一行一行写，页面当场判这一行；现在的 fill 是整张表一起批、而且不含中间行。
3. **能当场打勾的格子表**（比如 `grid` 组件：行名、列名、哪些格子该勾），页面逐格判、标出第一处错。海明码分组、Cache 组相联映射到哪组、页表有效位……很多「分类」题都是一张勾选表。
