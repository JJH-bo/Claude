## la-param　含参数的方程组

### 理想的教法

1. 先不算，让学生说出「$|A|\ne0$ ⇒ 唯一解」的理由（可逆 ⇒ 存在且唯一）。
2. 学生**自己**对含 $a$ 的行列式做「三行加到第一行、提出 $a+2$」，每一步页面核对，最后写出因式分解的形式（要求必须是因式分解，不接受展开式）。
3. 由因式读出两个特殊值。
4. 两个特殊值各自代进去，学生自己化阶梯形、数两个秩。
5. 最后把「唯一解」的范围写成数集；理想情况下再让学生自己对**含参数的**增广矩阵做行变换，自己决定在哪里分情况讨论（这才是考研真正要会的：先消元再分情况，而不是先代值）。

### 现有组件做到了哪些

- 第 1 块板：`quiz`（$|A|\ne0$ 时一定唯一解）+ `conjecture`（`grade: off`，半句话说存在、半句话说唯一）。
- 第 2 块板：`answer` 配 `formula: a`、`answer: det(A)`，`let` 里 `a = param`；解析里 `\calc{factor(det(A))}` 让页面写出 $-(a+2)(a-1)^2$。再一个 `type: interval` 问「$|A|=0$ 的 $a$」。
- 第 3、4 块板：`elim` 的 `mode: do`（增广矩阵、`target: ref`；第二个加 `write: rows` 让学生自己算变了的那一行），后面一个 `answer` 判两个秩 `[rank(A1), rank(M1)]`。增广矩阵用 `mat(col(A1,1), col(A1,2), col(A1,3), b)` 拼，不自己抄。
- 第 5 块板：`quiz` 判两种情况的结论（错项专门放「$|A|=0$ 所以都无穷多解 / 都无解」），`type: interval` 判唯一解的数集。
- 第 6 块板：`elim` 含参数 `param: a` 配 `ask: special, case`，作为整套讨论的对照。

### 想做但做不到的

- **学生自己对含参数的行列式做变换**：`det` 组件说明里没写支持 `param`，也没有 `mode: do`。我只能让学生在纸上算、在 `answer` 里交最终式子。想要：`det` 的 `mode: do` + `param: a`，学生写 `r1 + r2 + r3`、`r1 / (a+2)`，页面核对、记下「提出 $a+2$ 时要求 $a\ne-2$」。
- **只接受因式分解的形式**：`formula: a` 代值比较，展开式 $-a^3+3a-2$ 也算对。可「教到什么程度」要的是因式分解（因为下一步要读零点）。想要一个 `form: factored` 之类的限制（或者至少在记录里写「学生交的是展开式」）。
- **学生自己对含参数的增广矩阵消元并决定在哪分情况**：`elim` 的 `mode: do` 明确「不能含参数」。所以我只能先代值再分别化简，这其实和考研的标准做法（先消元，主元含 $a$ 时分情况）不一样。第 6 块板用 `ask: special, case` 补了一下，但那是页面做、学生猜，不是学生做。
- **含参数的 `mode: fill`**：说明里写了 `elim` 含参数时 `mode: fill` 每种情况一行（秩、解的情况）。我没用，因为和第 3～5 块板重复；但如果能「学生做行变换 + 页面在每种情况下要学生填秩」合在一起就最好。
- 代特殊值的矩阵 `A1`、`A2` 只能我手抄（没有「把 $a=1$ 代进 $A$」的函数，比如 `subs(A, a, 1)`）。抄错了页面查不出来。

### 写法上拿不准的地方

- `formula: a` 与 `let` 里的 `a = param` 同名：说明在 practice 里写过「配了 `formula: n` 时不能再取一个叫 n 的数」，那 `let a = param` 再配 `formula: a` 会不会冲突？`answer: det(A)`（`A` 含参数）能不能在代 $a=1..6$ 时求值？我两边都没把握，选了 `det(A)` 而不是手写 `-(a-1)^2*(a+2)`。
- `type: interval` 的答案是有限集合时怎么写：说明只给了 `a != 1 且 a != -2` 一个例子，学生那边认 `{1, -2}`。我写了 `answer: a == 1 或 a == -2`，是照着推的。
- `elim` 的 `b: \calc{b}`：说明只举了 `matrix: \calc{A}`，`b:` 字段里用 `\calc` 我是推的。
- `elim` 的 `mode: do` + `augmented: true` + `target: ref` + `write: rows` 四个一起用，说明里没有合起来的例子。
- `quiz` 能不能写 `id:`、`title:`：quiz 的说明里没有列字段，但第五节要求「会产生作答的组件都写 `id:`」。我写了 `id:`，没写 `title:`。

## la-power2　对角化求 Aⁿ（学生自己选 P）

### 理想的教法

1. 学生写出特征多项式、求特征值。
2. 学生自己解特征向量、选 $P$；页面按「每一列是特征向量、$P$ 可逆」判，并且**指出是哪一列不对**。
3. 后面所有板都用学生自己的 $P$：$P^{-1}AP$ 按学生的 $P$ 判；推 $A^n$ 时，板上显示的 $P$、$P^{-1}$、$\Lambda^n$ 也是学生自己的。
4. 讲清 $A^n=P\Lambda^nP^{-1}$（中间 $P^{-1}P$ 一对对消掉）。
5. 学生写 $A^n$ 每一格，代 $n=1$（及 $n=2$）检验。

### 现有组件做到了哪些

- `answer` 配 `formula: λ` 判特征多项式（`answer: λ^2 - tr(A)*λ + det(A)`，让页面算 tr、det）；`eig` 的 `mode: quiz` 判特征值。
- `answer` 的 `check:` 判 $P$：`det(ans) != 0`，以及每一列 `det(mat(A*col(ans, j), col(ans, j))) == 0`（$A\mathbf p_j$ 与 $\mathbf p_j$ 平行），每条带针对性的提示。
- `answer: inv(ans(q-P))*A*ans(q-P)`：按学生自己的 $P$ 判 $P^{-1}AP$。后面接一个 `quiz`：交换两列会怎样。
- `quiz` 探「$A=P\Lambda P^{-1}$ 还是 $P^{-1}\Lambda P$」这个误解；`derive` 一行行写出 $A^n=P\Lambda^nP^{-1}$，`\hl{mid}` 给 $P^{-1}P$ 起名字，方便以后 `mark`。
- `formula: n` 的矩阵答案逐格判 $A^n$；再用一个 `answer: A^2` 让学生代 $n=2$ 检验。

### 想做但做不到的

- **把学生的 $P$ 写上后面的黑板**：`ans(q-P)` 只说能用在 `answer:`、`check:` 里。想在第 4、5 块板写 `$P=\calc{ans(q-P)}$`、`$P^{-1}=\calc{inv(ans(q-P))}$`，或者在 `matrix` 组件里 `product` 学生的 $P$ 和 $\Lambda^k$，让学生看到「自己的那套」怎么乘出 $A^k$。说明没写，我没敢用。
- **$A^n$ 的标准答案按学生的 $P$ 来**：写 `ans(q-P)*diag(3^n, (-1)^n)*inv(ans(q-P))` 时，特征值的先后得跟学生 $P$ 的列走，我没法表达「第 $j$ 列对应的特征值」（没有取特征值、取矩阵元素的函数）。最后的 $A^n$ 不依赖 $P$，所以只好手抄了标准答案的式子（`(3^n + (-1)^n)/2` 等）。如果有 `eigvals(A)` 或「取 $(i,j)$ 元」`entry(M, i, j)` 就能全交给页面。
- **$P^{-1}AP$ 的「是对角的」**：现在的条件是我自己凑的（$A\mathbf p_j$ 与 $\mathbf p_j$ 平行用 2 阶行列式为 0 表达）；三阶时这招不灵（要用 `rank(mat(A*p, p)) <= 1`，说明没讲 `rank` 能不能用在 `check` 里、`<=` 比较行不行）。想要一个现成的 `isdiag(M)`。
- **检验那一步**真正想让学生做的是「把 $n=1$ 代进**自己写的式子**，看是不是 $A$」。页面已经代 $n=1..6$ 判过了，所以学生不需要自己检验；我只能退而求其次，问「代 $n=2$ 算出 $A^2$」，而学生完全可以直接算 $A\cdot A$ 绕过自己的式子。想要的是：`answer` 引用学生写的式子在某个 $n$ 的值（比如 `ansat(q-An, n=2)`），让学生预测/核对。
- 特征多项式的解析里 $(\lambda-1)^2-(-2)(-2)$ 这种符号式没法让页面算（`\calc` 不处理 λ，除非 `lambda = param`；可我又在同一节课用 `formula: λ`，怕同名冲突），只能手写。

### 写法上拿不准的地方

- `ans(q-P)`：学生交的 $P$ 没通过 `check`（比如不可逆）时，`ans(q-P)` 用的是学生那个错的 $P$ 还是标准答案？说明只说了「还没做就用标准答案」。若用错的、不可逆的 $P$，`inv(...)` 会怎样？
- `check:` 多行：我写成 `check:` 一行 + 两行续行（每行一个条件、各带 `=>` 提示）。说明说「一行一个或用 `;` 隔开」，又说「下一行没有字段名就算续行」，续行是不是算新的一条条件，我是推的。另外条件按顺序判吗？第一条 `det(ans) != 0` 不满足时后面的还会不会算（会不会因为后面有 `inv` 之类报错）？
- `formula: λ` 的 `answer:` 里混用 `tr(A)`、`det(A)`（`let` 里的矩阵）：说明的例子只有纯 λ 的多项式。
- `formula: n` 按格写矩阵时，格子里的 `(-1)^n` 是否被当作合法式子、学生能不能输入 $(-1)^n$（小键盘上有括号、乘方，应该行）。
- `eig` 的 `mode: quiz` 配 `goal: eig`：学生怎么输入「两个特征值」（顺序、分隔符）说明没写。
- `derive` 一行里 `\hl{mid}{(P^{-1}P)}` 后面还有很长的式子，在 iPad 竖屏上会不会挤出板外，我看不到。

## la-rank1　秩一矩阵的幂（练熟）

### 理想的教法

1. 先探误解：$\boldsymbol\alpha\boldsymbol\beta^{\mathrm T}$ 和 $\boldsymbol\beta^{\mathrm T}\boldsymbol\alpha$ 的形状。
2. 学生算出 $A$，看 $A^2$，发现 $A^2=3A$。
3. 学生自己用结合律推 $A^2=(\boldsymbol\beta^{\mathrm T}\boldsymbol\alpha)A$，页面逐行核对（不是看老师推）。
4. 归纳 $A^n$，算 $A^{10}$。
5. 页面换数练：先给 $\boldsymbol\alpha,\boldsymbol\beta$，再只给矩阵（要学生自己认出秩一、用 $\operatorname{tr}A$）。

### 现有组件做到了哪些

- `quiz` 单独探形状误解；`answer: a*b'` 判 $A$。
- `matrix` 的 `product A A` 让学生点 $A^2$ 的格子看来历；`answer: b'*a`（`before: A^2 =`、`after: \,A`）判倍数。
- `derive` 的 `mode: do`（`vars: a=vec(3) b=vec(3)`、`start: A^2`、`goal: (b'*a)*A`）让学生自己逐行推，页面随机取数核对。后面 `quiz` 问 $\boldsymbol\beta^{\mathrm T}\boldsymbol\alpha$ 等于 $\operatorname{tr}A$。
- `formula: n`（`answer: (b'*a)^(n-1)*A`）判 $A^n$；再问 $A^{10}$ 的指数。
- 两个 `practice` 的 `type: custom`：一个随机 $\boldsymbol\alpha,\boldsymbol\beta$ 求 $A^k=cA$ 的 $c$，一个随机秩一矩阵配 `formula: n` 写 $A^n$。

### 想做但做不到的

- **问 $A^{10}$ 本身**：答案是 $3^9A$，要学生写的是「$3^9A$」这个式子。`formula: n` 必须含 $n$；普通 `answer` 的格子只收整数、小数、分数，不收 `3^9*2` 这种式子，让学生手算 $19683\times2$ 毫无意义。只好退成「指数 $m$ 是几」（`answer: 9`），判分很弱、而且 9 是我写死的。想要：`answer` 收「数 × 矩阵名」的式子（不含 $n$ 的 `formula`），比如 `formula: none`。
- **练「认出秩一」**：只给矩阵时，最关键的一步是认出各行成比例。practice 只能判最后的 $A^n$，看不出学生是认出了秩一，还是硬乘出来的。想要 practice 每题前加一个选择小问（「这是秩一吗？」）或者和 `recognize` 混在一起出。
- `derive` 的 `mode: do` 推完以后，想让学生**接着**推到 $A^n$（归纳），但页面只能判「相等」，含 $n$ 的一般式不能逐行判。

### 写法上拿不准的地方

- `derive` `mode: do` 里 `vars: a=vec(3) b=vec(3)` 和本节课 `let` 块里的 `a`、`b`、`A` 同名：说明说组件自己的 `let` 同名时用自己的，`vars:` 是不是也一样优先，我是推的。
- 学生打 α、β：说明说「希腊字母都认」，例子里变量叫 `a`、`b`，却说 `αβᵀαβᵀ` 也认。α 是自动对应到 `a` 吗？我在板上让学生打 `a`、`b`，以防万一。
- `goal: (b'*a)*A` 是按「样子」判还是按「值」判？如果按值，`A^2` 这一行本来就和 goal 相等，学生第一行就「推完了」；如果按样子，学生写 `(a'b)A`（内积交换）或 `tr(A)A` 算不算到达 goal？说明只说「写到 goal: 那个样子就推完了」。
- `product A A name=A2`：同一个矩阵乘自己，说明的例子是 `product A B`，同名两次行不行没写。
- `practice` 里 `pick u = vec(3, -2, 2)`：取到零向量时 `w'*u` 为 0，会被 `where` 挡掉，应该没问题；但 `pr-mat` 里 `where tr(A) != 0` 对 3×3 的 `u*w'` 能取到的概率够不够（说明说发布时先试十几组，取不到会报）。
- `practice` 的 `q:` 里 `\calc{u}` 写出来是列向量（bmatrix），竖着占三行，`practice` 一题的高度我估计不准。

## 课堂（class.class.json，la-power2）

- 第一轮：`board plan` + `pin`（题目和 `let`）+ 新板 `answer formula: λ`。
- 第二轮：学生交了 $\lambda^2-2\lambda+5$（就是 $(\lambda-1)^2+4$，副对角的 $(-2)(-2)$ 被加上去）。按教法「换一道能把两种做法分开的题」：取 $\lambda=4$，`answer: det(4*E - A)`；对的算法得 5，按「加」得 13。
- 第三轮：「没懂，为什么？」判为缺知识（二阶行列式公式里的减号），直接讲：`board add` 一个 `derive`（`start: all`），用 `\hl` 给减号和副对角乘积起名，接着 `board mark` 两条（第一行一条、块里一条）圈出来；讲完让学生回去算 $\lambda=4$ 那题作确认。

拿不准：
- `let` 块写进 `board pin` 里行不行（说明说 `let` 放哪一段都行，没说常驻栏也算）。
- `\hl{minus}{-}`：只包一个减号，圈出来会不会太小、能不能找到。
- 同一轮里先 `board add` 一段 `derive`、再 `board mark term=` 指向它：说明说按顺序执行，应该等它画好；但 `derive` 默认一行一行写，我加了 `start: all` 保证要标的项已经出现。没写 `start: all` 时 mark 会不会找不到还没写出来的行，说明没讲。
- 学生的错答是 $\lambda$ 的式子，页面发来的 `[作答]` 行里会不会带「在 λ=… 上对不上」，我按 `answer` 的普通格式编的。

## 说明里第一次见到、拿不准的新写法

| 写法 | 我怎么用的 | 说明没讲清的 |
|---|---|---|
| `let` 里 `a = param` | la-param 整节课的 $A$ 含 $a$ | 和 `formula: a` 同名会不会冲突；`answer: det(A)` 在 `formula: a` 下能不能逐个代值；含参数的矩阵在 `\calc{A}` 里写出来是不是带 $a$ 的 bmatrix。 |
| `\calc{factor(det(A))}` | la-param 的解析 | 只能放在公式里显示；能不能用在 `answer:` 里（比如要求因式分解形式）没说。 |
| `type: interval` | la-param 的「$|A|=0$ 的 $a$」和「唯一解的范围」 | 只有一个 `answer:` 的例子（`!=` + `且`）。答案是**有限集合**（$\{1,-2\}$）时 `answer:` 怎么写：`a == 1 或 a == -2`？`{1, -2}`？我用了前者，是猜的。`或` / `且` 能不能混写、能不能写 `<`、`[ , ]` 也没说。 |
| `ans(编号)` | la-power2 的 `inv(ans(q-P))*A*ans(q-P)` | ① 学生的答案没过 `check` 时用哪一个；② 只能用在 `answer:` / `check:`，还是 `\calc{}`、`matrix`、`scene` 里也能用（我很想用）；③ 被引用的题在别的板上（我放在上一块板）有没有关系；④ 学生后来改了前一题的答案，这一题会不会重判。 |
| `check:` 多条 | la-power2 的 $P$ | 续行算不算新的一条；是否按顺序、遇到第一条不满足就停；条件里能不能用 `rank`、`<=`；`=>` 后面的提示里能不能有 `$…$`。 |
| `formula: n` 的按格矩阵 | la-power2 的 $A^n$ | 每格的标准答案能不能含 `ans(…)`；`answer:` 是表达式（不是字面矩阵，比如 `(b'*a)^(n-1)*A`）时是一个框还是逐格框——我在 la-rank1 里按「一个框」理解。 |
| `formula: λ` / `formula: a`（n 以外的变量） | la-power2、la-param | 说明说「别的变量也行」，只举了 λ；`a` 这种和 `param` 撞名的情况没说。`answer:` 里能否混用 `let` 的矩阵函数（`tr(A)`、`det(A)`）。 |
| `elim` 的 `mode: do` + `augmented: true` + `write: rows` | la-param 第 3、4 块板 | 组合用法没有例子；`target: ref` 配 `b`/`augmented` 时，最后一列算不算进阶梯形的判定。 |
| `elim` 的 `b: \calc{b}` | la-param 第 6 块板 | 只有 `matrix: \calc{A}` 的例子。 |
| `derive` 的 `mode: do` | la-rank1 第 3 块板 | `goal:` 是按样子还是按值判；`vars:` 和全课 `let` 同名的优先级；希腊字母怎么对应到 `vars` 里的名字。 |
| `matrix` 的 `product A A` | la-rank1 第 2 块板 | 同一个矩阵乘自己；结果的 `name=A2` 能不能被后面的 `\calc` 用（我没用）。 |
| `practice` 的 `pick … = vec(3, -2, 2)` | la-rank1 两个练习 | `vec` 写在「完整写法」里，`where` 里能不能直接写 `w'*u`（向量内积）没有例子。 |

## 如果组件库只能再加三样

1. **`elim` / `det` 的 `mode: do` 支持含参数**（学生自己对含 $a$ 的矩阵做变换，页面记下「这里除以了 $a+2$，要求 $a\ne-2$」，最后让学生自己列出要分开讨论的值，再各自填秩）。含参讨论是考研线代每年必考的，现在学生只能「先代值再化简」或者「看页面化」，最关键的「在哪一步分情况」没法让学生动手、页面判。
2. **`ans(编号)` 能用在 `\calc{}`、`matrix`、`scene` 里**，再加两个小函数 `entry(M, i, j)`、`eigvals(A)`（或 `isdiag(M)`）。这样「学生自己选的 $P$」能贯穿整节课：后面的板上显示的是学生的 $P$、$P^{-1}$、$P\Lambda^nP^{-1}$，标准答案也按学生的特征值顺序算，不用老师手抄 $(3^n+(-1)^n)/2$。
3. **不含 $n$ 的式子作答 + 形式要求**：`answer` 能收「数 × 矩阵名」「$3^9A$」这样的式子（`formula:` 不带变量），并能要求形式（`form: factored` 只认因式分解、`form: kA` 只认「数 × A」）。现在求 $A^{10}$、因式分解 $|A|$ 这种考研最常见的「写出最简形式」的题，页面要么判不了、要么判得太宽。
