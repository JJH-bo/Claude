# 验收题库（第三批）· 数据结构

## ds-nextval　next 和 nextval，练到熟

求模式串 `abaabcac` 的 next 数组和 nextval 数组（王道口径：从 1 数，next[1] = 0）。
（答案：next = 0 1 1 2 2 3 1 2；nextval = 0 1 0 2 1 3 0 2）

教到什么程度：自己求出每一格；说清 nextval 什么时候要再往前找；最后换几个模式串练到熟（页面出题、判分）。

## ds-avl　自己建平衡二叉树

依次插入 16、3、7、11、9、26、18、14、15，建一棵平衡二叉树，写出最后的层序序列。
（答案：11 7 18 3 9 15 26 14 16）

教到什么程度：每插一个学生自己判断落在哪、哪个结点失衡、做哪种旋转；最后写出层序序列。
