# 第 3 块板「FIFO 和 LRU 各换谁」

老师写在板顶的话：这句话说得对：FIFO 看调入时间，LRU 看最后一次访问的时间。现在用后半句做第 2 步：按 LRU 换谁？

## FIFO 和 LRU 各换谁
【分步例题 ex-b3】同一个串，两种规则
  3 个物理块，一开始都空。引用串 $1,\ 2,\ 3,\ 2,\ 1,\ 4$。前 3 次调入 1、2、3，第 4、5 次访问 2、1 都命中。第 6 次访问 4：缺页，物理块满了。
  第 1 步 按 FIFO：FIFO 看调入的先后：1 最早调入，换出 1。
  第 2 步 按 LRU：按 LRU，换出哪一页？
  选项：1 / 2 / 3

# 常驻栏
## LRU 的规则
缺页、物理块又满了时：换出**过去最久没被访问**的那一页（往回看，不往后看）。
## LRU 的规则
缺页、物理块又满了时：换出**过去最久没被访问**的那一页。
看每页**最后一次被访问**的时间，不看调入的时间（看调入时间的是 FIFO）。
