# 评卷：ds-nextval（数据结构，KMP 的 nextval）· 第 4 轮

误解：以为 nextval 就是 next（照抄或只差一点），不知道 T[j] = T[next[j]] 时要接着往前跳。

轮次都按 `transcript.md` 的「第 N 轮」写（老师是奇数轮，学生是偶数轮）。计划块关。这一轮老师的说明里多了：「引导式的讲法也要先让学生凭自己的理解做一次，做之前不把规则写上黑板或常驻栏」「确认题问的就是学生错的那个量」「没把握那一问单独一轮」「连对两次就别再一格格空转」。模拟课 8 轮老师，到第 15 轮为止，最后一题学生还没作答。

核对老师自己写的数：第 15 轮 aaaab 的 next 写的是 0 1 2 3 4，王道口径（从 1 数，next[1] = 0）**对**（nextval 是 0 0 0 0 4，所以 j = 4 的答案 0 也对）。前面 ababaa 的 next 0 1 1 2 3 4 也对（nextval 0 1 0 1 0 4），第 9、11、13 轮说的 nextval[3] = 0、j = 6 不白比、j = 5 落到 0 都对。

## 和上一次（第 3 轮）比

- **好在**：上一次老师用「先找白比、再造 nextval」的路绕开了误解，从头到尾不知道学生原来怎么想；这一次照新说明先让学生凭自己的理解写 nextval，第 4 轮误解原样暴露，第 5 轮点明，之后的建构式讲法接在探测后面，正是上一次评卷的第 1 条建议。确认题也照新说明问的是学生错的量（落脚点），按错法做得出看得出不同的数。没有用 kmp 演示的旁白（上一次旁白把递推先说了），全程用 `mode: quiz` 和自己写的 quiz，板上没有提前泄露规则。没有在 ababaa 上一格格空转：j = 3、6、5 三格各有用处（白比、对照、连退）。
- **差在**：上一次的确认题 aabaab j = 6 会在中途（2）停下，能分开「一路退到底」和「退到不白比为止」；这一次 j = 3、j = 5、aaaab j = 4 三个连退的例子全都落到 0，学生很可能把规则学成「白比就一路退到 0」。上一次「没把握」的问题是和新题挤在一轮，这一次第 13 轮干脆没问。

## 这一节的教法问题

1. **第一个例子分不开「再退一步」和「一直退」，提示又给得太满。** j = 3 退到 1 后，T[1] 失配以后 next[1] = 0 是被迫的，「每个落脚点都查一遍」在这个例子里根本用不上；第 9 轮的提示（「它失配以后去哪你刚算过了，能不能直接去那里」）加上板上「j → 1（白比一次）→ 0」，等于把答案写好了，学生第 10 轮一句「那就直接跳到 0 吧」没有任何推理，却标了有把握。学生从这里学到的是「白比就再退一步」，第 14 轮正是这样错的。第 9 轮可以只问「j = 3 失配，一步到位应该去哪」，不画链条；或者第一个例子就选一个要查两个落脚点的格。
2. **常驻栏的规则缺了「改到哪」。** 第 13 轮 k1 写「T[k] = T[j]：必然白比，要改」，没写要接着查下一个落脚点、直到不白比或到 0，学生照着它做，自然只退一步。第 15 轮口头补了「每一个落脚点都查一遍」，常驻栏却没改。应该在学生第 14 轮暴露以后，用 `replace` 把 k1 补上这一句（或等学生自己在第 16 轮说出来再补）。
3. **第 13 轮没先问哪一点不踏实。** 学生第 12 轮对条件「不太确定」，老师直接认定并钉上常驻栏，同一轮出新题，而新题的板上又替学生做好了条件判断。按说明，这一轮只问「你是哪一点拿不准」，或者出一格要学生自己判断条件的题（比如 j = 4：T[2] = b = T[4]，白比吗）。
4. **下一步的确认要有一个中途停下的格。** 三个连退的例子都落到 0，第 16 轮学生答对 aaaab j = 4 以后，还需要一格会在中途停下的（aaaab 的 j = 5 停在 4；或上一次用过的 aabaab 的 j = 6 停在 2），才能确认学生学的是「查到不白比为止」而不是「一路退到 0」。之后再回到第 4 轮学生照抄的那张表，让学生自己把 ababaa 的 nextval 整张写出来，和当初的 0 1 1 2 3 4 对一下。
