# 课后的数据：处理到对我有用（2026-11-03）

我问：每节课完后那一堆数据，现在处理得够不够好，有没有真正处理出对我有帮助的东西？开发这边用 ArtifactData 只读看了真数据（6 节课、2 份课后报告、152 条错题、37 个弱点、44 条掌握），结论是**收集得全，处理得不够**：

- 6 节课里 4 节没点下课：报告、抄题、整理全卡在「下课」那一步，这几节的作答没人处理。
- 证据只带开课时的块：11-02 那节 28 道题全记在第三章第一节，实际讲的是第一章；没有一道题有知识点。页面算掌握时把简单题和难题混着数，同一节课里先「基础题过」几分钟后「掉了」，块还是错的。
- 「谓语只圈一半」出现了三次（08-28、10-28、11-02），弱点 W40 的「最近」还停在 08-28；最有用的诊断只写在小结的文字里。
- 三选一的题 ✗✗✓ 是把选项试遍了，页面照样记「改对了」。

我说：加一个删课；数据管道和知识点账本现在做；给我看的部分看性价比做。**花额度多、收益不大的不做**。

## 做了什么

### 1. 删课（`memory/purge.js`）

「以前的课」点进去最下面「删掉这节课」，首页没下课的那一行也有「删掉」。删：这节课的黑板、对话、资料包、报告（`SESSION_SCOPED`）、证据、观察、改动单、抄进题库的题、这节课记的错题。留：守则用到的失误（去掉课号，记 `wasSession`）、弱点挂着或被更正指着的错题；这节课改过的弱点、复现组、守则、规则不动（它们是记忆本身）。删之前先改自检的指纹，自检不会报「历史被删了」。不调用 Claude。

### 2. 数据管道（不调用 Claude）

- **挂着没下课的课**：停了 3 小时没动静，首页先按现有证据算一份暂时的报告（`report.provisional`），课照旧能接着上；后来又有动静、再停下，再算。
- **旧报告重算**：`REPORT_VERSION` 2，`sessions.report.v` 比它旧的首页打开时重算。
- **试出来的**：单选题三个选项第二次才对、四个选项第三次才对，`items[].guess`（`report.js` 的 `guessed`；`quiz` 的作答记下选项数 `options`）。报告、页面写「试出来的」。掌握里本来就当失手。
- **掌握按课算**（`mastery.js` 的 `walk`）：还没过时，一节课里只算最后一次失手以后的干净题；过了以后，复现只看那节课一上来那道。不再一节课里一会儿过、一会儿掉。
- **页面以前算的结论按新规则重算**（`startOf`）：最后几次改状态是页面算的（`by: page`），就退回页面算之前的状态重算；我和以前对话里定下的不动。11-02 那次「讲过 → 掉了」这样会改回来。

### 3. 知识点归类（`memory/skills.js`，一节课调用一次 Claude）

报告写好以后（下课的、暂时的、重算的），首页调用一次 Claude（Opus 5.5，effort medium）：发报告每道题一行、这一科的课程地图、用过的知识点、开着的弱点、小结开头（十几 KB），回来每道题一行 `item 题号 块#短名 [弱点]`，新知识点先写 `point`。存进 `sessions/{编号}.skills`。

- 掌握：证据换上「真正的块 + 知识点」的标签再数（`retagEvidence`），课程地图上块下面列出知识点和各自的状态，新的知识点带标题。
- 弱点：每个弱点出现几次（错题档案 + 归类挂上的，同一节课不重数）、最近哪天、之后它牵涉的知识点一次做对过几道（`weaknessHits`）。弱点表、课堂 Claude 的记忆摘要里写着。不改弱点表本身。
- 花费：一节课一次，约 4～6 千 token 输入（真课一节 100～350 万 token）。调用不了 Claude 时不归，掌握照旧按整块算。

### 4. 给我看的（不调用 Claude）

- 「以前的课」每节课最上面「这节课学到哪了」：会了、还不稳（错几道、当堂改过来没有、挂了哪个弱点）、下次先测，下面可以展开按知识点的表。
- 首页「上一节」下面写「下次先测」。
- 课堂 Claude 的记忆摘要里，上一节那一行后面带「页面按知识点算的：会了…还不稳…下次先测…」（几十个字，每轮多带的很少）。

## 没做的

- **课上让课堂 Claude 自己写 `point=`**：要改课堂说明，每一轮都多带，而且真课里它几乎不写；下课后归类一次更省。
- **弱点自动改证据级、自动关**：页面只写出次数和之后做对几道，改不改还是课堂 Claude 和我决定（结论要挂证据，红线照旧）。
- **删 assets 里的原图**：别处（错题、补记）可能还指着。

## 5. 记忆摘要装得下这节课真正要用的（2026-11-03 第二轮）

用真数据拼了一份英语课的「对学生的了解」（每一轮都带，32 KB）：55 条通用规则占了 13.7 KB（规则最多能占六成），守则、关于我又是 8.6 KB；这一块的 10 道错题里 9 道、掌握整段被挤进目录，课堂 Claude 只看得到编号。原因还有两个：上一节课的错题块记成了开课时的块（第三章），按块找不到；`list()` 把每节课归类的弱点读成了字符串，最近挂上的弱点也找不到。

改了什么（`digest.js`）：

- **装的先后和写出来的先后分开**（`PACK_ORDER`）：先装这一块的（上一节停在哪、这一块、弱点、掌握、要记的、以前的课、错题，合起来最多 `CORE_SHARE` 0.45），再装关于我、规则（最多 `RULES_SHARE` 0.42，原来 0.6）、守则；一节里一条放不下只停这一节，不再「后面的全不放」。目录先留 `CATALOG_RESERVE` 5 KB（原来 7 KB，真数据里目录 3～4 KB）。
- **规则的先后**（`RULE_ORDER`）：红线 → 讲解 → 教法 → 黑板 → 掌握 → 检验 → 细则 → 来源；正文写着【红线…】的按红线排。装不下的进目录（编号 + 一句话）。
- **最近两节做过题的课**（不算练习、只说话的课）记的错题、归类时挂上的弱点都算相关（块记错了也找得到）。
- **提到学生不用「他」「她」**（`neutral`）：记忆原文里的换成「学生」，「其他」「他们」不动；下课整理的失误清单也一样（`memo.js`）。
- **失误按它那节课分科**（`space.js` 的 `spaceOfShared(d, mem)`）：英语课记的失误不再跟着数学、408 下课整理。
- **点进课看一眼不算动静**（`report.js` 的 `lastActivity`，首页判断挂着的课要不要先算暂时的报告）。

数据（开发那边，记了 log）：`rule-c2`、`rule-c3` 改成「要背的写进内容（==…==、remember 粉框），不逐项圈」（原来写的「\\hl 起名再逐项 mark」正是 11-03 学生不满意的做法）；「考研数学」那条关于我标上数学。

效果（同一份真数据，英语课）：这一块和最近一节课的 8 道错题原文、5 个弱点、掌握、关于我全部在全文里；规则 46 条在全文、9 条（细则）进目录；整份照旧 32 KB 以内，不多花。

守着（`tests/memory-digest-fit.test.js`）：66 条长规则 + 12 条守则 + 25 条关于我的时候，这一块和最近一节课的错题、弱点、掌握、关于我、上一节停在哪一定在全文里、整份不超 `MEMORY_BUDGET`、规则多出来的进目录、【红线】一定在；「他」「她」不出现；失误不串科；open 不算动静。
