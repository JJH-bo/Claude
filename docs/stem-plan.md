我说要把数学和 408 的教学再提升一次（2026-11-03），组件库和整体教学都算。上一轮（`docs/quality-plan.md`）做完以后，验收第 1 轮（`evals/results.md` 的 1-phase5）的摩擦报告列了五门课「最想要的」，到现在只做了「学生逐行推导」（`derive` 的 `mode: do`）。教法在 11-02 按教学尺子的评卷改过（`TEACH_PROBE`），改完线代、408 都没重跑。这份按这两样排。

原则照旧：上课不多花额度（出题、判分、诊断都是页面代码）；写错了在页面上报出来；iPad 上点得准；每门课系统里的组件说明 ≤ 40 KiB（线代、数据结构现在都只剩不到 1 KiB，新写法放进「完整写法」，或者先把别的挪进去）。

## 分批

### 第 1 批：演示组件当练习题（摩擦报告第 2 条）

- `practice` 的 `use: 组件名`：随机取数照自定义题型写（`pick` / `let` / `where`），下面接那个组件的写法，字段里用 `\calc{a}` 写取到的数。每一题换一组数，组件用 `mode: quiz` / `mode: fill` / `ask:`（照写），判分、错法诊断都是现成的引擎。
- 取数加两种：`bits(位数)`（一串 0/1，海明码、CRC、乘除法用）、`seq(个数, 最小, 最大)`（页面引用串、排序的数据），写进字段时是空格隔开的一串。
- 常用的演示组件内置出题（不写 `pick`）：`practice use: hamming` 就够了，页面自己出合适的数。先做摩擦报告点了名的：`mul` `div` `fadd` `hamming` `crc` `frag` `kmp` `huffman`，再加 `sort` `paging` `sched` `subnet` `bsearch`。
- 记录、信心标定、练一练（`drills`）都照 `practice` 走：一题一条，带错法。

### 第 2 批：演示组件上的滑块（摩擦报告第 5 条）

- 演示组件的 `vary:`：`vary: d = 1..10 step 1 km`，字段里写 `\calc{d}`，拖滑块时页面拿新值重算整个演示（停在同一步）。计网最想要（距离、速率、帧长、窗口、MTU），所有演示组件都能用。课堂里 `figure set d=…`、`figure play d` 也能动。

### 第 3 批：答案（摩擦报告第 4 条）

- 引用前面的答案：`answer` 的 `check:` 里写 `ans(id)`，取学生在 id 那道题写的答案（线代：学生选的 $P$ 不同，后面 $P^{-1}AP$ 照样判对）。
- 新答案类型：区间（`type: interval`：含参讨论的「$a\ne 1$ 且 $a\ne -2$」「$(-\infty, 1)\cup(2,+\infty)$」）、方程（`type: equation`：平面、直线方程，两边同乘一个数也对）、定点数（`type: fixed`：`00.1011`、双符号位、小数点、补码）。

### 第 4 批：学生自己动手、页面逐步判（摩擦报告第 1 条）

- 过程表：改进型 CLOCK 每一轮的访问位、修改位、指针，分区分配每一步的空闲分区表，进 `mode: fill`（`cols:` 选哪几列）。
- 计网：`encode` 的 `mode: do`：学生点半个码元画波形，页面逐个码元判。
- 建树：二叉排序树 / AVL / B 树插入时学生在图上点它落在哪、选哪种旋转 / 要不要分裂（已有的 `ask` 补齐到每一次插入都能问），哈夫曼已经能点。

### 第 5 批：含参数的精确计算（摩擦报告第 3 条）

- `\calc`、`let` 认一个参数（`let t = param`）：行列式、特征多项式、$A^n$ 写成含参数的式子；`answer` 的矩阵答案每格可以写含 $n$ 的式子。看工作量，做不完的写明。

### 第 6 批：量一遍

- 验收第 3 批题（线代、408 各几题，专挑这一轮的新写法会用上的），一次写对率。
- 教学尺子重跑线代、408 的两个场景（`TEACH_PROBE` 改后），再加一个数据结构的场景（next / nextval 混用）。评卷看出的教法问题改进进 `prompt.js`。
- 说明书补上摩擦报告第 6 条那些拿不准的地方。
