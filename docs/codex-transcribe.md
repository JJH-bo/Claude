# 让 Codex 转教材（贴给 Codex 的话）

学习台里不转写（`docs/textbook-plan.md`）。省 Claude 的额度时，让我电脑上的 Codex（命令行或桌面版，读得到本地的 PDF）转，转好的文本推进我的**私有**仓库，Claude Code 用 `node tools/books.mjs text` 读回、写进学习台的收件箱 `book_inbox`，学习台自己拼条目。原页图照常在学习台「存进学习台」（先转后存、先存后转都行：存的时候选同一本书，只给缺图的页补图，不动转写）。

格式和学习台原来让 Claude 转写的规矩一样（`kit/src/books/ingest.js` 的 `transcribePrompt`），读回用同一个 `parseTranscription`。下面这段整个贴给 Codex，改掉【】里的：

---

我在准备考研，下面是我自己手里这本教材的扫描版 PDF：【PDF 在电脑上的路径】，书名《【书名】》。请把它逐页转写成文字，存进我的私有仓库【仓库地址】的 `【书号，比如 B3】/` 文件夹，给我自己的学习系统用（只给我自己复习，不对外发布）。

怎么做：

- 这是扫描版，没有文字层。每页先渲染成图片（比如 `pdftoppm -r 150 -png`，或者 Python 的 PyMuPDF），**看图转写**；不要拿 PDF 的文字提取结果代替看图。
- 「第 N 页」指 **PDF 的第几页**（从 1 数，就是阅读器里显示的那个页码），不是书上印的页码。
- 这次转第【82】页到第【412】页。**先只转第【82–91】页，推上去以后停下来等我检查**，我说可以了再接着转。
- 每 10 页一个文件，文件名写起止页：`【B3】/p082-091.txt`、`【B3】/p092-101.txt`……UTF-8。每转完两三个文件就 commit、push 一次。

转写的规矩（一个字、一个数都不能错，以后老师上课按这些文字讲）：

1. 忠实转写：不总结、不改写、不补充、不纠正原书。每个数字、符号、上下标、矩阵元素都照原页。看不清的地方写【看不清】，不要猜。
2. 公式用 LaTeX：行内 `$…$`，单独成行的 `$$…$$`；矩阵 `\begin{pmatrix}…\end{pmatrix}`，行列式 `\begin{vmatrix}…\end{vmatrix}`，方程组 `\begin{cases}…\end{cases}`。正文里的普通文字不要放进 `$` 里。代码照原样写，保留缩进。
3. 按内容切成「条」，类型只能是：定义、定理、性质、推论、公式、例题、习题、方法、说明、图表。例题连同它的解答放在同一条，定理连同证明放在同一条；一段讲解是一条「说明」。
4. 章节标题单独一行，类型写「标题1」（章）、「标题2」（节）、「标题3」（小节），后面是标题原文，下面不写正文。
5. 每条的名字：例题、定义、定理照书上的编号和名字写（如「例2.1」「定理3」「01.【解答】」）；说明写这段讲什么（十个字以内）。
6. 一条跨页：下一页开头接着写的那一条，名字照抄上一页那条的，开头那行末尾写 `| 接上页`，正文只写这一页上的部分。
7. 图：类型写「图表」，正文用一两句话说图里画了什么（结点、箭头、标的字）。表格用 Markdown 表格转写。
8. 页眉、页脚、页码、书名水印、广告不要。整页是空白或只有装饰，那一页只写 `=== 第 N 页` 就行。

文件里只写下面这种格式，不要别的话、不要用 Markdown 代码块包起来：

```
=== 第 82 页
--- 标题2 | 2.3 线性表的链式表示
--- 定义 | 单链表
线性表的链式存储又称单链表……
--- 例题 | 例2.1
解：……$O(n)$……
=== 第 83 页
--- 例题 | 例2.1 | 接上页
……
```

## 转好以后（Claude Code 这边）

我跟 Claude Code 说「Codex 转好了 B3 第 82–91 页，仓库是……」。它：

1. 把私有仓库接进会话（`add_repo`），拉下来。
2. `node tools/books.mjs text --book B3 --src 仓库/B3 --work 工作目录`：读回、检查（缺页、【看不清】、字特别少的页），打印要写的收件箱记录；新书加 `--title 书名 --space cs --subject 数据结构 --total 总页数`。
3. 抽几页对着学习台里的原页图看一眼（有原图的话），格式、准确度没问题再 `ArtifactData batch` 写进 `book_inbox`。
4. 告诉我检查结果；第一批没问题，让 Codex 接着转。
