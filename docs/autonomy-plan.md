## 0. 定下来的事（不要再改方向）

- **外部 Claude 只做开发**（Claude Code 改代码、发布学习台、必要时修数据）。学习、备课、整理、改记忆全在学习台里。
- **不加第三个 Claude。**课堂里的 Claude 就是学习台的管理者：它写的记忆能直接生效，我事后看、不对就撤销。只有两样还要我点确认：**规则**（每一轮都整段带着，写错一条每节课都受影响）和**掌握**（我的红线：课堂不能宣布掌握；页面按证据算、我确认，这套不变）。
- **判断标准：放权不花额度，多调用才花。**写记忆用输出里的 `memo` 块，不多跑轮。每一项都写清以后的花费：不花 / 每轮多带一点 / 多调用。**会多调用的不做，除非特别重要。**
- **记忆不冗杂：**重复的及时合并，照抄的代码直接拦，每类有条数上限；合并、清理顺着已有的下课整理那一次调用做，不另外调用。

## 4. 第 2 批：不冗杂

三道关，都不另外调用 Claude：

1. **代码拦照抄**（写的那一刻，`memo.js`）：
   - 新弱点、新复现组和这一科已有的一条几乎一样（`similarity`，跟守则一样的阈值），就不新建，告诉它改那一条；
   - 同一道题（同组件同一步，`itemKey`）已经有没解决的错题，就不另建，这次的证据挂到那条错题的弱点上。
2. **条数上限**（每科，照 `LESSONS_MAX` 的做法；数字等第 0 步量完再定，先按 弱点 15、在用的复现组 10、偏好 20）：到了上限新的不收，提示先合并。
3. **定期合并**，顺着下课整理那一次调用做：
   - 每科每 5 节课一次；某一类到了上限的那节课也做一次；
   - 那次的 `closingPrompt` 多带一段这一科的目录：在用的弱点、复现组、守则、偏好、没解决的错题，一行一条；
   - 要它写合并和清理：`weakness id=W3 status=merged into=W1`、`review id=R4 status=retired why=…`、改写留下的那条；
   - 合并、退役都能撤销，被合并的那条在摘要里不再带（`digest.js` 跳过，跟守则的 retired 一样）；
   - 花费：那一节课的下课调用多带约 3～6 KB，平均每节课约一两千 token，不多跑轮。
4. **规则一次性整理**（第 0 步量出来规则每一轮约 14.5 KB）：开发这边把重复的、过时的、只该给外部的列成清单，做成改动单（`by: chat`），**我在首页「待确认」里看过再确认**（能一条条改、不要，也能全部确认）：
   - 「他」→「学生」：19 条（照原意，只换称呼）。
   - 作废（讲的是外部 Claude、旧流程）：rule-bd-6（外部实时黑板）、rule-i-mem（读 current-state.md）、rule-mat-1（对话里读 PDF 的办法）、rule-out-1（对话客户端不渲染 LaTeX）；rule-pk-2 只留前一句。
   - 合并：rule-i-d4（条件给全再出题）并进 rule-i-r7（检验题三条的 (a) 已经包含）。
   - 改写：rule-i-05「掌握由老师判定」→「掌握由页面按我写出来的东西算、我确认」（和现在的做法对上）。
   - 只管数学的标 `space: math`（408、英语的课不再带）：rule-chk-1、rule-chk-3（1000 题）、rule-i-src1～3（张宇的教材、文稿、板书）、rule-i-geo、rule-t-5（第 0 讲）。
