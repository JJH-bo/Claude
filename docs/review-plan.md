# 计划：复习和复现（会不会做、记不记得，两条线）

接在 `docs/learning-plan.md` 后面。2026-11-03 我问「学习后的复习、巩固复现，学习台够不够好」，看了真数据以后答案是不够：

- 21 个复现组里 19 个过期，多数从 9 月下旬起没动过；线代 12 组、408 6 组。复现只挂在**这一科的新课开头**，我最近上英语，别的科就一直不复现。
- 题库只有 23 道、全是英语一块，线代和 408 一道没有；「练一练」和复现课从没用过；掌握里「复现通过」是 0 个。
- 「练一练」的题是课上原样抄的，可我的规则（rule-rev-2）写着：复现通过要隔天、**新题（不是原题换数）**、不贴标签、无提示、写出依据。原题再做对，掌握却会算成复现通过。
- 要背的东西（定义原文、哪种排序稳定、复杂度、系动词有哪些）没有地方单独记：复现组一组七八个点，按组排期太粗，`card` 记忆卡只能翻面，不记想没想起、不排下次。

我说「按你觉得对的方式去做」，于是分成两条线。

## 1. 会不会做：复现组（`reviews`）

- **原题不算复现通过**（`mastery.js` 的 `isOriginal`：题库编号 `d-…` 的作答做对了不算干净，做错照样算失手）。练一练做完，复现组有一道没一次做对就直接记没过；都对了档位不动（`drills.js` 的 `drillOutcome` 返回 `practiced`），页面上写「原题都对了，不算复现通过」。
- **今天复现**（`views.js` 的 `reviewQueue` / `todayReviews`）：首页「今天」不分科，每门课一行「到期几组」，按我的规则 rule-pre-2（从没复现过 > 上次没过 > 过期久）先挑 `REVIEW_MAX`（3）组，点「复现这 3 组」开一节复现课；排着的收起来，每组也能「只复现这一组」。一节课只上一门课（课堂按门课带组件说明和教法），所以不跨门课混。
- **几组一起的复现课**（`reviewPack(mem, [ids])`）：资料包带每组的内容、盯的弱点、错题原文（几组时每组最多 4 道）、以前同一块的题和那几节课的一页；计划写明：每组至少一道新题、混着出不说是哪一组、不是原题换数、一道题尽量测组里的几个点、只测到一部分的照最弱的一点判、没测到的点 `add="…"` 记进那一组下次先测。`main.review` 是编号数组、`reviewClass: true`；`sessions.review` 是编号数组。
- **下课每组判一次**（`prompt.js` 的 `closingPrompt({ review, opening })`）：复现课每组写一行 `review id=… result=`；备课写的「开头复现」（`[{ id, how }]`）以前会被 `createClass` 原样记成 `sessions.review`（下课时变成「复现组 [object Object]」），现在记成 `sessions.opening`，下课时只判做了的那几组。
- 资料包写成文字时（`plan.js` 的 `lessonPlanText`），复现课写成「这节课复现 R3、R5、R1」，不当成开头复现。

## 2. 记不记得：记忆点（`recall`）

- 新的一类（`schema.js`，状态类，编号 `K12`）：`q` 问法、`a` 标准答案、`block`、`space`、`tier`（1 → 3 → 7 → 14 → 30）、`last`、`result`（`got` / `vague` / `miss`）、`lapses`、`status`（`active` / `done` 记牢了 / `void`）、`session`、`log`。到期 = `last` + `tier`，页面算。
- **谁写**：课堂里的 Claude 用 memo 的 `recall q="…" a="…"`（默写没写出的、讲过要背的；改问法 `recall id=K3 q=…`，不用记了 `status=void`），一节课最多 8 条（`SESSION_CAPS.recall`），和这一科已有的几乎一样的不收，一科最多 `RECALL_CAP`（300）条；新的一条从明天排（当天刚讲的不测）。下课整理单也提醒它记要背的。我能在首页「自己加一条」（`meChange('recall-add')`），在「管理 → 我改记忆」里「不用记了」（`recall-void`）。
- **每天想一遍**（`recall.js` 纯函数 + `recallrun.js` 画面）：首页「要记的」，各科到期的混在一起，一次最多 `RECALL_N`（20）条，没想起过多的、过期久的在前，挨着的尽量不同块。先自己写出来（Apple Pencil 直接在框里写），再看答案，自己点：想起来了升一档（30 天那档也想起来了：`done`）、模糊档位不动、没想起回 1 天并 `lapses + 1`。不让页面替我判（要背的东西说法不一）；写一样时提示一句。每想一次记一条证据（`src: recall`，带写的什么），**不进掌握**（掌握按做题算）。不调用 Claude。
- **课堂看得到**（`digest.js`）：记忆摘要多一节「要记的」：这几块记过的和老想不起的（`lapses ≥ 2`），最多 12 条——课上不重复记，老想不起的换个讲法再讲一次。`memory_read` 也能取 `recall`。
