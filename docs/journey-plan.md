# 离考研多少天、「这一周」、课前热身（2026-11-03）

我说：想要既实用、帮学习的功能，也要一点情绪价值，还有倒计时，考试是 **2027 年 12 月 21 日**。
条件照旧：页面按记录算，**不调用 Claude，也不进发给课堂 Claude 的说明**（不影响回复的快慢、不花额度）。

## 做了什么（`kit/src/memory/journey.js`，纯函数；画面在 `desk.js`、`desk.css`）

- **倒计时**：学习台顶上日期那一行「11月3日 星期二 · 离考研 413 天」，每一页都看得到（`EXAM_DATE`、`countdownText`）。
- **这一周**（首页右边一栏最上面，`weekLines`）：只说真发生了的事，语气平实、不夸（我的「关于我」里写着不夸、不铺垫）：
  - 连着学了几天（今天还没学就数到昨天；只是点进课看一眼不算，`studyDays` / `streak`）；
  - 这 7 天学了多少分钟、几天，和前 7 天比（按每节课报告里去掉空档的时长，`weekMinutes`）；
  - 今天到期的复现和要记的都做完了（今天学过、而且都清零时才说）；
  - 真实的进步（`improvements`）：以前哪节课错过的知识点、最近一节一上来就对了（「双宾和宾补的区分：11/02 错了 5 道，今天一上来就对了」）；哪一块升到基础题过 / 复现通过；
  - 每科讲到哪（`progress`）：一条进度条，浅色是讲过的块、深色是过了的块；一科里只有一门课时写课名（数学现在只有线代，就写「线代」）。
- **课前热身**（`warmupDrills`）：上一节有「下次先测」的知识点、题库里有那节课上的原题，主角卡上出「课前热身 N 题」：开一节练习（`kind: drill`、`warmup: true`），页面判分，不调用 Claude；做完掌握照常算（原题，不算复现通过）。
- **积压分摊**（`backlogDays`）：复现卡上「一共 21 组到期：一次 3 组，7 次清完（排在后面的不会丢）」。

## 没做的（下次可以接着做）

- 每周一首页的一页周报（更长的版本）。
- 照现在的速度算「哪天讲完」：课程地图里数学只有线代、408 只有数据结构，算出来会误导，先不做。
