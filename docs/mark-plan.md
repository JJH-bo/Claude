# 板书标注做到老师的水平

2026-11-03 真课：板上一片字，不突出重点；我让课堂 Claude 圈，它只能把「he / she / it」「不定代词」这种字塞进公式里用 `\hl` 起名字再圈（字体变成公式体），一项一个小椭圆，椭圆还压着序号和旁边的字。

## 毛病在哪

1. **找不到目标**：能标的只有公式里起了名字的项、矩阵、演示的步、图上的东西、英文单词。中文、普通文字、列表的某几条都指不了。
2. **画法不对**：每一处单独一个椭圆；椭圆要包住一行宽字，得比字宽出一半、高出一截，就压到左右和上下行的字。
3. **画法太少**：没有老师常用的「大括号 + 要背」、波浪线、着重号、对错号；荧光笔盖在字上面，字发灰。
4. **写板时没法直接标重点**：只能加粗、换颜色。

## 做了什么（版本 2026-11-03u）

- 标哪里（`markspec.js`、`marks.js`）：
  - `text="板上的字"`：任何一段字（`textfind.js`：不管空格、大小写、全角半角；「…」隔开头尾；`#2` 第几次，不写标第一次并提醒）。
  - `li=1-4`、`para=2`、`tr=2`：列表的几条、第几段、表格的几行（定义 / 重点 / 易错框里的照常数，作答、演示组件里的不数）。
  - `to="…"`：从这里画箭头指到那里；同一行的从上面或下面拱过去（看哪边空）。
- 画法（`markdraw.js`）：
  - 圈、框、大括号把一组东西合成**一个**形状（几行字、几条列表），一组列表连序号一起圈。
  - 宽的圈是圆角长圈（`loopPath`），方的一小块（公式里一项、图上的标签）照旧是椭圆；留白按四周离别的字多远定（`roomAround`、`padsFor`），线落在空隙中间。
  - 跨几行、头尾不齐的半句话沿着字的形状圈（`lassoPath`）。
  - 新画法：`brace` 大括号（旁注写在括号尖外面）、`double` 双下划线、`wave` 波浪线、`dots` 着重号（每个字下面一个点）、`tick` ✓ / `cross` ✗（默认绿 / 红）。
  - 荧光笔 `highlight` 画在字下面一层（`.mk-under`，宿主 `isolation: isolate`），深色黑板涂浓一点、浅色纸淡一点（`--mk-fill-a`）。
  - 量字的范围（`inkRect`）连直接写在元素里的字一起量，不按整行宽（大括号才不会跑到行尾外面）。
- 写板时就标：`==涂黄==`、`=={pink}要背==`（`render.js` 的 `hlmark`，`mark.hl-mark`）。
- 说明：课堂（`prompt.js` 的 mark 一节，先写「怎么选」）和说明书第六节；只在英语课用的按词数（`word=` `words=` `phrase=` `blank=`）挪到英语的教法里，给线代腾地方（线代的整份说明离上限只剩几百字节）。教法里加一句：每块板的结论、要背的都要标出来。
- 出现了好几次没写第几次：标第一次，跟着下一条告诉课堂 Claude（`warn`，不算写错，不多跑一轮）；实时黑板写进 ops 的结果行。

## 看效果

`class-demo.html?dev` 先打一句话，再打：

- 「测试:标注旧」：真课里那块板的标法（对照）。
- 「测试:标注」：同一块板现在的标法：大括号 + 要背、例外圈红、荧光笔、波浪线、`==涂色==`。
- 「测试:标注圈」：一组要背的画一个大圈。
- 「测试:标注全」：✓ ✗、着重号、跨行半句的圈、划掉、双下划线、拱形箭头。
